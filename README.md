# Mini_Projet2D — Jeu Vidéo 2D sur Unity

## 📋 Description du projet
**Mini_Projet2D** est un projet de jeu vidéo 2D développé dans le cadre de ma formation en Techniques de l'informatique. Ce projet met en pratique la structuration d'un projet sous le moteur Unity, la gestion des scènes, ainsi que l'implémentation de mécaniques de gameplay et d'animations fluides pour le personnage principal.

---

## 🛠️ Technologies et Outils Utilisés
* **Moteur de jeu :** Unity (version 2D)
* **Langage :** C#
* **Gestion des animations :** Unity Animator (State Machine, Blend Trees / Paramètres d'animation)
* **Contrôle de version :** Git, GitHub, Plastic SCM

---

## 🎮 Fonctionnalités principales & Implémentations
* **Déplacement du joueur :** Gestion des entrées (Input System / Legacy Input) pour un contrôle fluide du personnage dans un environnement 2D.
* **Système d'animation (Animator) :** 
  * Implémentation des états **Idle** (immobile) et **Move** (déplacement).
  * Configuration des transitions basées sur les paramètres du script C# (ex. vitesse ou vélocité du joueur).
* **Architecture de projet :** Organisation rigoureuse des dossiers (`Assets`, `Packages`, `ProjectSettings`, scripts de gestion).
